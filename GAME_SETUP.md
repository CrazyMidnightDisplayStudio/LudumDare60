# Настройка игрового flow

Все игровые скрипты находятся в `Assets/Scripts`. Компонент `GameInterpreter`
переименован в `GameManager` с сохранением `.meta`/GUID: ссылки из терминала и
`TerminalButtonInput` в сцене сохраняются.

## Пять загадок и финал

На существующем объекте `GameManager` настройте компонент `GameManager`:

1. В `Puzzles` должно быть ровно пять элементов в порядке прохождения.
2. В каждом элементе задайте `Password`, UI-объект `Led` и массив реплик
   `Radio Monologue`. Пароли должны быть непустыми и различаться.
3. Назначьте `Signal Source` (AudioSource, выведенный в SFX AudioMixer Group)
   и `Correct Password Sound`.
4. Настройте ответы `Correct Password Response`, `Wrong Password Response`
   и `Final Text`. Финальный текст выводится в терминале после пятого пароля.
5. Назначьте существующий `FadeManager` в `Fade Manager` либо создайте его
   на постоянно активном объекте. Его `Fade Image` — чёрный UI Image,
   закрывающий экран и расположенный поверх остального UI.

LED выключаются при старте, зажигаются по одному и остаются включёнными.
Неверный, уже использованный или будущий пароль не продвигает игру.
Пробелы по краям ввода удаляются. `Ignore Password Case` по умолчанию включён.
Для чувствительных к регистру паролей выключите этот флаг.

После пятого пароля новый ввод в терминал блокируется. Затем игра ждёт
`Final Input Delay` и отпускания удерживаемых кнопок. Следующее действие
запускает fadeout. Учитываются клавиши, кнопки мыши/тача/геймпада,
колесо и стики геймпада; движение мыши учитывается при включённом
`Finish On Mouse Movement`. Действие, которым отправлен последний пароль,
не пропускает финальный текст.

Без пяти настроенных паролей игра сообщает об ошибке конфигурации в Console
и не принимает ввод. Настоящие пароли и тексты загадок в код не зашиты.

## Радио и монологи

1. Добавьте `RadioMonologue` на постоянно активный объект, например `GameManager`.
2. Назначьте `Radio`, `Game Manager` и `Contact Frequency`.
   Частота хранится целым числом: `13600` отображается как `136.00`.
3. Создайте отдельную UI-панель монолога и назначьте её в `Panel`.
   Компонент `RadioMonologue` должен оставаться снаружи этой панели,
   поскольку панель скрывается после разговора.
4. В `Line Text` назначьте TMP текста реплики. `Speaker Text` необязателен.
   Имя связного задаётся в `Speaker Name`.
5. Настройте `Characters Per Second`. Значение `0` показывает реплику сразу.

Монолог текущей загадки начинается, когда приёмник настроен на частоту связного.
Промежуточные цифры незавершённой настройки не считаются новой частотой.
ЛКМ или Space сначала допечатывает текущую реплику, затем переключает следующую.
Последнее нажатие закрывает панель. Закрывающий Space/клик не попадает в терминал.

Во время монолога ввод в терминал заблокирован. При уходе с частоты разговор
прерывается; при возвращении начинается заново. Уже завершённый монолог сам
по кругу не запускается. Чтобы прослушать его ещё раз, уйдите с частоты и
вернитесь либо вызовите `ReplayCurrentMonologue()`.

Если связной уже на текущей частоте, после правильного пароля начинается
монолог следующей загадки. После пятого пароля монологов больше нет.

## Кнопки громкости

Используйте один существующий `AudioVolumeManager` на объекте `GameManager`.
В `On Click()` соответствующих UI Button назначьте:

- громкость вверх — `IncreaseMasterVolume()`;
- громкость вниз — `DecreaseMasterVolume()`;
- выключить/вернуть звук — `ToggleMasterMute()`.

`Volume Step` задаёт шаг от 0 до 1. Mute сохраняет предыдущий уровень.
Изменение громкости кнопками снимает mute. Если микшер не назначен, Master
управляет `AudioListener.volume`; при назначенном микшере все источники
звука должны быть выведены в его группы Master/SFX/Music.

Кнопки громкости и прочие служебные кнопки держите вне `Keyboard Root`
терминала: этот объект содержит символьные клавиши, Enter и Backspace.

## Проверка в Unity

1. Введите неправильный пароль и правильный пароль будущего этапа:
   прогресс и LED не должны меняться, сигнала успеха нет.
2. Введите первый правильный пароль: загорится только первый LED,
   прозвучит один сигнал. Повторный ввод этого пароля не продвигает игру.
3. Настройте радио на частоту связного: проверьте печать, допечатывание,
   переключение реплик, выход с частоты и повторное подключение.
4. Закройте монолог Space: в терминале не должен появиться пробел.
5. Введите все пять паролей по порядку: LED останутся включёнными,
   финальный текст появится один раз. Удерживаемый Enter не запускает fadeout.
6. После отпускания клавиш и задержки новое действие запускает затемнение.
7. Проверьте громкость вверх/вниз до границ 0 и 1, mute и восстановление уровня.

Проверка графики, звука, UI-ссылок и фактического затемнения требует Unity Editor.
